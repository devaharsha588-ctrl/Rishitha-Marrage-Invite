# ✨ Project Overview

The website is built to feel like a **cinematic wedding film** instead of a normal webpage.

The experience uses:

- Full-screen visual scenes
- Scroll-driven animation
- WebGL scene transitions
- Shader-based image blending
- Cinematic typography
- Tirupati-inspired visual elements
- Responsive mobile-first design
- Background wedding music
- WhatsApp attendance interaction
- Countdown
- Google Maps navigation

The design is inspired by the interaction quality of premium creative websites and the cinematic storytelling style of wedding invitation websites.

The reference used during development was:

https://demos.riwaaz.in/rameswaram/

The reference was used only for inspiration in interaction, pacing, composition and storytelling. No proprietary Riwaaz assets, branding or source code are used.
